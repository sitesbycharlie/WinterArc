How Progression Works
• Every lift has a rep range. Compounds 6-10 or 8-12, isolations 10-15 or 12-20
• Warm-ups don't count. All working sets at the target weight
• Rest times are shown on every exercise. If reps drop by more than 2 between sets, rest longer
• Every working set at the top of the range: weight goes up next session
• Otherwise: same weight, beat last session's reps
• No progress for 3 sessions on a lift: drop 10% and rebuild
• Last set within 1 to 2 reps of failure. If it felt easy, it didn't count
